# 约会 App 素材库

本目录保存用户提供的原始视觉素材。原图保持不变，开发时从原图复制、剪裁或派生，避免覆盖源文件。

## 目录结构

- `source/icon-sheets/`：10 张图标合集或完整背景图。
- `source/transparent-icon-sheets/`：4 张带有效 Alpha 透明通道的图标合集。
- 后续开发建议将裁切结果放入 `generated/icons/`，并使用语义化文件名。

## 使用规范

- 原始图仅归档，不直接覆盖或修改。
- 一张图含多个元素时，按网格单独裁切，并保留发光、柔和阴影和半透明边缘。
- 裁切文件使用语义化命名，例如 `date-movie-ticket.png`、`food-dessert.png`、`card-fireworks.png`。
- 页面内图标保持统一尺寸、透视和阴影强度，不在同一区域混用明显不同的风格。
- Dating 卡片优先从 `gpt2.png`、`gpt4.png` 和四张完整爱心场景中选择主视觉。
- 生成卡片时使用本地素材，避免跨域或离线加载失败。
